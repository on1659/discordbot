TypeScript에서 이벤트 버스 패턴 구현하는 방법 알려줘
ZAI · glm-4-plus
TypeScript에서 이벤트 버스 패턴을 구현하는 방법을 설명드리겠습니다. Node.js의 EventEmitter를 활용한 타입 안전한 구현: 
import { EventEmitter } from 'events';

interface EventMap {
  'user:login': { userId: string };
  'data:update': { key: string; value: any };
}

class TypedEventBus {
  private emitter = new EventEmitter();

  emit(
    event: K, data: EventMap[K]
  ) {
    this.emitter.emit(event, data);
  }

  on(
    event: K,
    handler: (data: EventMap[K]) => void
  ) {
    this.emitter.on(event, handler);
  }
}
이 방식의 장점은 타입 안전성을 보장하면서도 간단하다는 것입니다.

싱글턴으로 만들려면?
ZAI · glm-4-plus
앞서 만든 TypedEventBus를 싱글턴으로 만들려면: 
class EventBus {
  private static instance: EventBus;
  private emitter = new EventEmitter();
  private constructor() {}

  static getInstance(): EventBus {
    if (!EventBus.instance) {
      EventBus.instance = new EventBus();
    }
    return EventBus.instance;
  }
}

export const eventBus =
  EventBus.getInstance();
또는 더 간단하게 모듈 레벨에서 인스턴스를 export하는 방법도 있습니다. ES 모듈은 기본적으로 싱글턴이니까요.
